# Render → Environment (полностью бесплатно)

Обязательные: `BOT_TOKEN`, `OWNER_ID`, `WEBAPP_URL`, `GAME_DB_HOST`, `GAME_DB_PORT`, `GAME_DB_USER`, `GAME_DB_PASSWORD`, `GAME_DB_NAME`, `WAIP_MASTER_FERNET_KEY`.

**Сохранение данных (бесплатно через Telegram):** `BACKUP_CHAT_ID` — id приватного канала для резервных копий (вида `-100...`).
Как получить:
1. В Telegram создай канал → сделай его **приватным**.
2. Настройки канала → Администраторы → добавь своего бота с правами: публикация сообщений, редактирование, удаление, закрепление.
3. Перешли любое сообщение из канала боту @getidsbot — он покажет ID. Вставь его в `BACKUP_CHAT_ID`.

Подписка: `CHANNEL_USERNAME` (или `CHANNEL_ID`), `CHANNEL_URL`. Бот должен быть админом канала.

Экономика и хеш: `PASSWORD_HASH=md5`, `MONEY_PER_STAR=2000`, `MONEY_MIN_UNITS=100000`.

НЕ задавай `DB_PATH` и `TENANTS_DIR`. Не задавай `PORT` — Render задаёт сам.

Проверка: в Logs после запуска должна быть строка «Резервное копирование в Telegram включено».
При первом запуске «Резервной копии в канале нет — стартуем с чистой базы» — это нормально.

## WAIP STUDIO — сайт автодонатов (необязательно)
Открывается по адресу `https://<сервис>/studio/`. Нужен **отдельный бот** (создай в @BotFather) — он принимает оплату 250 ⭐.

| Переменная | Что это |
|---|---|
| `STUDIO_BOT_TOKEN` | токен отдельного бота студии (НЕ тот же, что `BOT_TOKEN`) |
| `STUDIO_ADMIN_LOGIN` | логин главного админа сайта |
| `STUDIO_ADMIN_PASSWORD` | пароль главного админа (поменяешь переменную — пароль сменится) |
| `STUDIO_PRICE` | цена бота в Stars, по умолчанию `250` |
| `STUDIO_MOD_PERCENT` | доля модератора, по умолчанию `60` (остаток остаётся боту) |

Без `STUDIO_BOT_TOKEN` сайт выключен. Нужны также `WAIP_MASTER_FERNET_KEY` и `WEBAPP_URL`.

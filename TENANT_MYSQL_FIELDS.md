# Поля анкеты нового магазина

При создании дочернего магазина анкета должна запросить:

1. Название магазина (показывается в интерфейсе).
2. HEX-цвет оформления (`#RRGGBB`).
3. Логотип/стикер (необязательно).
4. Telegram Bot Token от BotFather.
5. Telegram ID главного администратора.
6. MySQL: `GAME_DB_HOST`, `GAME_DB_PORT` (обычно 3306), `GAME_DB_USER`, `GAME_DB_PASSWORD`, `GAME_DB_NAME`.
7. Таблица аккаунтов (по умолчанию `accounts`) и колонки: `name`, `level`, `admin`, `money`, `skin`, `password`, `donate`.
8. Метод хеширования пароля: `plain`, `md5`, `sha1`, `sha256`, `double_md5` или `whirlpool`.

## Порядок проверки

- Проверить токен запросом Telegram Bot API `getMe`.
- Проверить подключение к MySQL и выполнить `SELECT 1`.
- Проверить наличие таблицы и колонок через `INFORMATION_SCHEMA.COLUMNS`.
- Только после успешной проверки сохранить настройки и разрешить запуск дочернего процесса.
- При любой ошибке не запускать магазин; показать пользователю конкретную причину.

## Важно

В текущем V4 `mysql_probe(..., check_schema=True)` проверяет соединение, таблицу и обязательные поля. Проверка `donate` теперь тоже включена. Полноценный пользовательский мастер создания дочерних ботов, менеджер процессов и автоматическое применение обновлений ещё не подключены к обработчикам Telegram — этот документ фиксирует требования для следующего этапа, а не утверждает, что мастер уже работает.

Пароли и токены нельзя хранить в открытом виде или включать в ZIP. На фото пользователя присутствовали реальные на вид реквизиты MySQL; их следует сменить, если они действующие.

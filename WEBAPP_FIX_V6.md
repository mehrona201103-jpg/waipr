# WAIP SHOP V6 — исправление Mini App и проверки подписки

## Что исправлено
- Добавлены отсутствовавшие элементы интерфейса `pfStarsRate` и `pfMoneyRate`, из-за которых JavaScript обращался к `null` и показывал `Cannot set properties of null (setting 'textContent')`.
- Добавлен скрытый совместимый элемент `payCrypto`, чтобы оставшийся старый UI-код не падал после удаления CryptoBot.
- Уведомление `toast` теперь безопасно обрабатывается, если элемент отсутствует.
- При запуске обычной ссылкой вне Telegram показывается понятное сообщение вместо ошибки API `Нет initData`.
- Сверены все обращения `$("...")` в `app.js` с ID в `index.html`: отсутствующих ID нет.

## Важно для Render / Telegram
1. `WEBAPP_URL` должен быть HTTPS URL вашего сервиса, например `https://ваш-сервис.onrender.com`.
2. В `@BotFather` Mini App должен открываться через кнопку `web_app` бота. Не открывайте `https://...onrender.com` вручную в Chrome: обычный браузер не передаёт Telegram `initData`.
3. В Render → Environment задайте `CHANNEL_USERNAME` без `@` для публичного канала. Для приватного канала задайте `CHANNEL_ID` вида `-100...`.
4. Добавьте бота в канал администратором. Для проверки членства через `getChatMember` Telegram требует, чтобы бот был администратором канала.
5. После изменения Environment нажмите Manual Deploy → Deploy latest commit (или перезапустите сервис). Затем в Telegram закройте Mini App полностью и откройте заново кнопкой бота.

## Если кнопка «Подписаться» открывает не тот канал
Проверьте, что `CHANNEL_USERNAME` — именно username нужного канала без `@`, либо используйте `CHANNEL_ID` для приватного канала. Убедитесь, что бот добавлен в этот же канал администратором.

## Что проверено в сборке
- Python-файлы компилируются через `py_compile`.
- `app.js` проходит `node --check`.
- Все статические ID, запрашиваемые из `app.js`, присутствуют в `index.html`.
- ZIP проверен на целостность после упаковки.

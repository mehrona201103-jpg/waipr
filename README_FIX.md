# Исправление архива и параметры MySQL

Архив пересобран в стандартном ZIP DEFLATE без `__pycache__` и `.pyc`, чтобы его мог открыть встроенный распаковщик Windows.

В `main.py` проверка схемы MySQL теперь также проверяет колонку `donate`, потому что магазин использует её для выдачи донат-валюты.

Поля анкеты нового магазина и последовательность проверки описаны в `TENANT_MYSQL_FIELDS.md`.

**Ограничение текущей сборки:** пользовательский мастер создания дочерних ботов, запуск отдельных процессов дочерних ботов и автоматическое распространение релизов пока не реализованы в Telegram-обработчиках. Не запускайте эту сборку как готовую мультибот-платформу.

Курс донат-валюты зафиксирован в `config.py`: `DONATE_PER_10_STARS = 100`, то есть 100 доната = 10 Stars (1 донат = 0,1 Stars). Это пока настройки курса; полноценная кнопка/платёжный сценарий покупки доната не подключён.

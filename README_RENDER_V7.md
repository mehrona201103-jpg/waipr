# WAIP SHOP — исправления доступа и скорости

- Владелец с Telegram ID из `OWNER_ID` пропускается проверкой обязательной подписки.
- Для остальных проверяется статус Telegram: creator/administrator/member; restricted принимается только при `is_member=true`.
- Ошибка API проверки пишется в Render Logs с подсказкой о правах бота и ID канала.
- Поддерживается `CHANNEL_URL` для приватной invite-ссылки.
- Логотип переведён в WebP 720×720 с приоритетной загрузкой.
- Полный список Render Variables: `RENDER_VARIABLES.md`.

Для реальной проверки бот должен быть администратором канала. Проверь `OWNER_ID`: это ID твоего личного Telegram аккаунта, а не ID канала и не ID бота.

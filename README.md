# WAIP SHOP V3 — базовое обновление

## Что изменено
- В стартовом экране вместо квадратной иконки установлен предоставленный круглый логотип WAIP SHOP.
- Удалён CryptoBot: в интерфейсе и API остаётся Telegram Stars (XTR).
- Курс игровой валюты: 100 000 валюты = 50 Stars; минимум — 100 000 валюты / 50 Stars.
- Добавлен параметр цвета WEBAPP: `/webapp/?theme=%23RRGGBB` (пример: `/webapp/?theme=%23ff5500`).
- Удалены встроенные секреты из `config.py`. Все секреты теперь необходимо задавать через переменные окружения.

## Обязательные переменные окружения
`BOT_TOKEN`, `OWNER_ID`, `GAME_DB_HOST`, `GAME_DB_PORT`, `GAME_DB_USER`, `GAME_DB_PASSWORD`, `GAME_DB_NAME`, `CHANNEL_USERNAME` или `CHANNEL_ID`, `WEBAPP_URL`.

Установи зависимости:
```bash
pip install -r requirements.txt
python main.py
```

## Важная безопасность
В исходном загруженном V2-файле обнаружены реальные значения BOT_TOKEN и доступа к игровой MySQL. Они были удалены из V3. Считай их скомпрометированными:
1. Отзови старый токен у @BotFather (`/revoke`) и создай новый.
2. Смени пароль MySQL и проверь журнал доступа к базе.
3. Вставляй новые значения только в Environment Variables хостинга, не в ZIP/GitHub.

## Что ещё не включено в V3
### Копирование ботов и обновления
В V2 нет мультиарендной системы. Для безопасного создания отдельных ботов нужна центральная управляющая служба, отдельное хранилище настроек/заказов каждого магазина, безопасное хранение токенов, управление процессами и маршрутизация Mini App. Простое клонирование `main.py` с другим токеном не создаёт независимый рабочий бот и конфликтует за порт WebApp. Поэтому кнопка «Создать такого бота» не добавлена как фиктивная функция.

### RUB-оплата
В V2 нет интеграции провайдера RUB и webhook подтверждения оплаты. Надпись «каталог rub» не идентифицирует платёжный API. До интеграции нужна точная платёжная система и её документация/API credentials. Не включать ручное подтверждение как «автоматическую оплату».

### Еженедельные 20%
Telegram Bot API не позволяет одному боту автоматически переводить Stars с баланса другого бота. Для автоматического распределения 20% нужны внешняя платёжная система/договорённый payout API либо единый приём платежей центральным мерчантом. Без этого нельзя честно обещать автоматический перевод между ботами.

## Технические замечания
- Суммы Stars рассчитываются сервером; клиентский интерфейс не является источником цены.
- Установи HTTPS для Telegram Mini App.
- Не запускай два экземпляра одного токена одновременно.
